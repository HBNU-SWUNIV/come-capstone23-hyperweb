## <u>프로젝트 소개(Project Overview)</u>
  ### 제목(Title)
  반려동물에게 맞춤형 자연식 레시피를 추천해주는 공유 플랫폼  
(A community platform that recommends personalized natural food recipes for pets)  

<br/>

- ### 개요
![그림1](https://github.com/user-attachments/assets/1c56346d-62eb-4585-865b-98f1d1386583)

반려동물의 수가 증가함에 따라 시장도 확대되고 있습니다. 그러나 그에 따라 사료의 영양 균형이나 위생면에서의 문제도 지적되고 있습니다.
그러다 보니 자연식에 관심을 갖는 주인들이 늘고 있고, 이번 프로젝트는 사용자들에게 레시피를 추천하는 SNS 서비스를 제공하기 위해 제작하였습니다.  
(As the number of pets continues to grow, the pet food market is also expanding. However, concerns have been raised about the nutritional balance and hygiene of commercial pet food.
This has led many pet owners to turn their attention to natural food, and this project aims to provide an SNS-style service that recommends personalized recipes for their pets.)  

<br/>

## 🌟 주요 기능 (Key Features)

| 기능 | 설명 (Korean) | Description (English) |
|------|---------------|------------------------|
| 🐾 **반려동물 프로필 & 회원 관리** | 반려동물의 이름, 나이, 체중, 알레르기 등 건강 정보를 등록<br>사용자 계정 생성 및 로그인 기능 | Register pet health data such as name, age, weight, and allergies<br>Support for user signup and login |
| 🍽️ **식단 자동 추천** | 반려동물의 특성에 따라 맞춤형 레시피 자동 추천<br>1일 / 30일 단위 식단 구성 가능 | Automatically generates custom recipes based on each pet's characteristics<br>Supports 1-day and 30-day meal plans |
| 🧠 **AI 레시피 가이드 체험** | 실제 데이터를 기반으로 추천 흐름 체험<br>더미 데이터를 활용한 미리보기 UX 제공 | Experience recipe recommendations using real sample data<br>Preview UX using dummy data |
| 📝 **SNS 스타일 레시피 공유** | 다른 사용자들과 레시피 공유 및 열람 | Users can share and browse recipes posted by others |
| 📊 **영양소 분석 및 시각화** | 영양 균형을 시각적으로 확인<br>부족한 영양소를 파악하여 개선 | Visualize the nutritional balance of each recipe<br>Identify and improve nutrient deficiencies |
| 💬 **직관적인 UI/UX** | 접고 펼 수 있는 반응형 사이드바<br>간결하고 쉬운 인터페이스 제공 | Responsive sidebar with toggle<br>Clean and easy-to-use interface |
